## Q&A and Tips for #OneUiLSFont 

1. Q : Unable to open the Downloaded File?

- A : Some browser will turn download file to ".bin" , edit that back to ".zip"

2. Q : What to do with the .zip?

- A : APK inside

3. Q : Unable to install APK inside?

- A : Only OneUI 6+ is supported

4. Q : Unable to find the font in lockscreen editor?

- A : Scroll to the end of the font section and press the 3 dots

5. Q : Support Clocks from GoodLock OR Lockstar OR ClockFace ?

- A : No,only those provided by System Will works

6. Q : Unable to adjust the Clock Size freely? Or Buggy Clock UI?

- A : Try Disable "Card" Notifications on Lockscreen , Use "Dots" or "Icons"
     - In Settings App - Notification - Lockscreen 

7. Q : Source of this project and credits?

- A : https://github.com/HeheJuice/OneUI-Lockscreen-Font-EXT

8. Q : Support Us?

- A : Star our Github , reacting with our post and joining us is enough❤️
